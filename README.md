# Regression

## 📈 Linear Regression Project

A beginner-friendly Python project that demonstrates linear regression, a machine learning technique used to understand relationships between variables and make predictions.

## ✨ Features

- **Simple Model:** Uses linear regression to learn from sample data.
- **Prediction:** Predicts an output for a new input value.
- **Visualization:** Displays actual data and the regression line.
- **Beginner Friendly:** Easy-to-understand Python code.

## 🛠️ Technologies Used

- Python
- Scikit-learn
- Matplotlib

## 🚀 Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the Python program:

```bash
python Regression.py
```

The program displays a prediction and plots the regression line.
